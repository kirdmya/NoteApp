# Обзор архитектуры

## Общая структура

- Слой интерфейса (UI) (`src/ui`) зависит от корневой композиции приложения (`src/app/App`).
- Бизнес-логика располагается в `src/core`.
- Хранилище данных и сетевой слой вынесены в отдельные модули и взаимодействуют через интерфейсы.

## Направление зависимостей

```
ui → app → (core → storage, network, infra)
```


Зависимости направлены сверху вниз:

- `ui` зависит от `app`
- `app` связывает все модули воедино 
- `core` работает через абстракции
- `storage`, `network`, `infra` содержат конкретные реализации
