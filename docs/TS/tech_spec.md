# Техническое задание
## Проект: O-range — приложение для заметок с возможностью масштабирования в базу знаний
Версия ТЗ: 0.1 (архитектурная)
---

# 1. Введение

## 1.1 Назначение документа

- ведения личных текстовых заметок
- организации заметок в иерархическую файловую структуру
- поддержки нескольких рабочих пространств
- дальнейшего масштабирования до системы уровня "база знаний"

Документ учитывает:
- текущую минимальную реализацию (v0.1)
- архитектурное масштабирование
- расширение функционала без переписывания ядра

---

# 2. Цели проекта

## 2.1 Основная цель (v0.1)

- работа с текстовыми заметками (.txt, .md)
- хранение данных в обычной файловой системе
- управление рабочими пространствами
- отображение древовидной структуры папок и файлов
- открытие файлов во вкладках

## 2.2 Стратегическая цель

- персональная база знаний
- инструмент управления знаниями
- расширяемая платформа (возможные плагины)
- кросс-платформенная система

---

Приложение предназначено для:

- индивидуального использования
- хранения заметок в папках

  - систему ссылок

# 4. Функциональные требования

---

# 4.1 Рабочие пространства (Workspace)

## 4.1.1 Общие положения

Приложение должно поддерживать несколько рабочих пространств

Workspace — это корневая директория на диске, содержащая вложенные папки и файлы .txt и .md

## 4.1.2 Требования

- Возможность создать workspace
- Возможность открыть существующий workspace
- Возможность переключения между workspace
- Workspace хранится как путь в настройках приложения

---

# 4.2 Работа с файлами

## 4.2.1 Поддерживаемые форматы

- .txt
- .md

## 4.2.2 Возможности

- Создание файла
- Переименование файла
- Удаление файла (перемещение в корзину ОС)
- Открытие файла во вкладке
- Сохранение файла
- Горячие клавиши для сохранения

## 4.2.3 Ограничения

- На этапе v0.1 автосохранение не реализуется
- Поддержка любых языков в названии файла
- Запрещены только системно-недопустимые символы

# 4.3 Работа с папками

# 7. Этапы разработки

Цель до v1.0: стабильный файловый менеджер для заметок (workspace + дерево + вкладки + редактор + поиск) с качественным UI/UX, без плагинов/кастомизации/облака/графов/ссылок.

---

## Принципы 
### Архитектура и зависимости
- UI (`src/ui`) не знает про файловую систему напрямую
- Хранилище (FS) — в `src/storage`, только через интерфейсы из `core`
- `app` — композиционный корень: собирает зависимости, конфиг, DI вручную

### Данные и формат
- На всём пути до v1.0 данные — папка на диске*(workspace)
- Файлы: `.txt`, `.md` (на v1.0 Markdown — это просто текст, preview можно оставить на будущее)

### Надёжность
- Нет потери данных: подтверждения, обработка ошибок, восстановление вкладок
- Всё, что может сломаться (удаление/переименование/кодировки) — имеет UX и сообщения

# v0.2 — Workspace + дерево файлов (первый “полезный” релиз)

**Статус: реализовано.**

Сделать основу файлового менеджера:
- выбрать папку workspace
- увидеть дерево
- базовые операции: создать/переименовать/удалить


### Workspace
- Команда: `File → Open Workspace…`
- Выбор папки через стандартный диалог ОС
- Сохранение последнего workspace в настройках
- Авто-открытие последнего workspace при запуске (если путь валиден)

### Дерево файлов
- Левый сайдбар: папки + файлы `.txt/.md`
- Фильтрация:
  - показывать папки всегда
  - показывать файлы только поддерживаемых форматов
- Контекстное меню:
  - `New Folder`
  - `New File…` (выбор расширения: txt/md)
  - `Rename`
  - `Delete` (в корзину)
  - `Reveal in Explorer` (опционально)

### Storage
- Реальная реализация `FileSystemRepository`:
  - list directory 
  - create file/folder
  - rename
  - delete-to-trash (через OS API / Qt)
- Ошибки FS отображаются в статусбаре + диалог

### Ленивая загрузка дерева (важно)
- Не грузить весь workspace рекурсивно
- Дерево раскрывается по мере раскрытия узлов

## UX детали
- Если workspace не выбран — дерево пустое, справа стартовый экран (“Выберите рабочее пространство”)
- После открытия workspace статусбар показывает путь
- При ошибке прав доступа — понятное сообщение

## Готовность версии
- Можно открыть workspace и видеть дерево
- Можно создать папку и файл
- Можно переименовать и удалить

### Редактор
- Справа: вкладки + текстовый редактор

- Поддержка UTF-8

### Вкладки

- `Ctrl+S` — сохранить текущую вкладку

- Обработка конфликтов:

### Дополнительное качество жизни
- Пункт меню `File → New File` создаёт и сразу открывает
- “Переименовать файл” в дереве обновляет заголовок вкладки

## Архитектура
- В `core` появляется:
  - `DocumentSession` (состояние вкладки: путь, текст)
  - `DocumentManager` (открытие/закрытие/список)
- В `ui` — только представление.

# v0.5 — Надёжность, большие папки, системные кейсы

- большие деревья
- изменения вне приложения
- ошибки диска

### Производительность
- Индикатор загрузки дерева (если нужно)

### Отслеживание внешних изменений

  - если файл изменён вне приложения и вкладка без несохраненных → обновить автоматически (или предложить)

- Обработка:
  - нет прав

  - файл занят другим процессом
  - удален другим приложением / ОС
- Логи:
  - файл логов (debug)
  - сообщения пользователю — человеческие
- Задавать вопросы формата "а что если...?"
